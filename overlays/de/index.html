⭐ Broadcast-Grafiken, die auf deinem eigenen PC laufen

iRacing Overlays ist eine Sammlung kostenloser, selbst gehosteter Broadcast-Overlays, gebaut mit Python + Flask. Jedes Overlay ist ein kleiner lokaler Webserver, den du in OBS Studio als Browser-Quelle einbindest. Alle Telemetriedaten werden lokal über das iRacing-SDK via pyirsdk gelesen — keine Abos, keine Konten, nichts in der Cloud, und nichts verlässt deinen Rechner, solange du nicht ausdrücklich die optionale öffentliche Freigabe aktivierst.

Über ein Dutzend Overlays laufen parallel, jedes auf einem eigenen Port, gestartet und gestoppt aus einem Ein-Klick-Desktop-Launcher. Daneben steht iCASControl, ein vollwertiges Rennleitungs- und Stewarding-Dashboard für Race Directors. Es ist dasselbe Toolkit, mit dem wir die CAS-Community-Rennen streamen — und es gehört dir, kostenlos, auf GitHub.

🔒 Privat von Grund auf

  • Läuft komplett auf deinem RechnerJedes Overlay ist ein lokaler Webserver. Die Telemetrie wird vom iRacing-SDK auf demselben PC gelesen; die Daten berühren keinen fremden Server.
  • Keine Konten, keine Abos, keine GebührenVon GitHub klonen und starten. Es gibt nichts zu registrieren und nichts zu bezahlen — jetzt nicht und später nicht.
  • Du entscheidest, was geteilt wirdEine optionale, schreibgeschützte öffentliche Ansicht (via kostenlosem Cloudflare-Tunnel) lässt Zuschauer ein Self-Service-Chart öffnen — und nur die freigegebenen Pfade sind erreichbar. Alles andere bleibt lokal.

⚡ Noch am selben Abend einsatzbereit

Wer Python installieren kann, kann das hier betreiben. Repo klonen, Abhängigkeiten installieren und den Launcher starten — dann die gewünschten Overlays als Browser-Quellen in OBS einbinden.

git clone https://github.com/halvar20000/iracing-overlays.git
cd iracing-overlays
pip install -r requirements.txt
# dann launch_gui.bat doppelklicken
